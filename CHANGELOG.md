# Changelog

## 1.0.0

First public release

- 265 flags: every country, plus England, Scotland, Wales, Northern Ireland, Catalonia, Galicia, the Basque Country, the European Union and the United Nations
- Region chips and search by name, country code or common nickname such as UK, USA or Holland
- Round, rectangle or square flags in four sizes, each with the country's name underneath
- Drag a flag onto the board or click to add it in view; repeated clicks line up in rows
